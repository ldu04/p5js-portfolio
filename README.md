# p5js-portfolio

p5.js 로 만든 인터랙티브 스케치 실습 모음이다. `index.html` 이 네 개 과제를 iframe 으로
한 페이지에 모아 보여준다.

| 폴더 | 과제 | 내용 |
|---|---|---|
| `sample1/` | 과제 1 — 정적 그래픽스 | 기하 도형과 색채 배열로 구성한 정적 화면 |
| `sample2/` | 과제 2 — 수학적 패턴 | 반복문 기반 픽셀 단위 패턴 연산 |
| `sample3/` | 과제 3 — 동적 애니메이션 | 프레임 기반 시간 변화 렌더링 |
| `sample4/` | 과제 4 — 인터랙티브 시스템 | 마우스·키 입력에 반응하는 동적 시스템 |

각 폴더는 `index.html` · `sketch.js` · `style.css` 세 파일로 독립 실행된다.

## 실행

```bash
# 저장소를 받은 뒤 정적 서버로 열면 전체 목록이 보인다
python -m http.server 8000
# → http://localhost:8000
```

`sample*/index.html` 을 브라우저로 직접 열어도 개별 스케치는 동작한다.

숭실대학교 사이버강의 과제로 수행했다.
